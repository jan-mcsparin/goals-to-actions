# ADR-001: An installable, mobile-first web app

**Date:** 2026-10-26 · **Status:** Accepted (revisited 2026-11-09)

## Context

The app is used mostly on a phone, many times a day, by one person at first. The founder's background is web development (front end, back end, distributed systems), with little native mobile experience.

## Decision

Build a mobile-first progressive web app, installable to the phone's home screen, also usable on a laptop for deeper planning.

## Consequences

- Fastest path to a usable app, in familiar tools; updates ship instantly with no app store review.
- Gives up home-screen widgets, deep Apple Health/Watch integration and the most reliable offline behavior.
- Native stays possible later (e.g. wrapping the web app with Capacitor) if those features become important.

## Revisited 2026-11-09

Compared Capacitor, Expo and two separate apps. The common pattern: Capacitor for an existing web app or PWA (minimal rewrite), Expo for a new mobile-first app, and two apps sharing one backend mainly for teams with a substantial web product.

Decision stands: build the PWA. If an App Store app is wanted later, Capacitor is the first step (plus a small Swift widget if a home-screen widget is wanted). Switch to Expo only if a truly native app becomes part of the goal before much UI is built.
